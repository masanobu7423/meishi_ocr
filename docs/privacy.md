# 名刺スキャン プライバシーポリシー / Privacy Policy

最終更新: 2026-10-25

## 日本語

名刺スキャン（パッケージ名 jp.tobishoku.meishi_ocr、以下「本アプリ」）は、名刺を撮影して内容を読み取り、端末の連絡先に登録するアプリです。

### 収集する情報
本アプリは、利用者の情報をサーバーに送信しません。通信機能を持たず、解析（アナリティクス）や広告の SDK も含みません。

### 端末内で扱う情報
- カメラで撮影した名刺の画像、およびアルバムから選んだ画像
- 画像から読み取った文字と、利用者が修正した項目（氏名、会社、電話番号、メールアドレス、住所など）
- 利用者が入力したメモ
- 利用者の修正から学習した補正ルール

これらは端末内のアプリ専用領域（`Android/data/jp.tobishoku.meishi_ocr/files`）にのみ保存されます。バックアップ機能で作成した zip ファイルも同じ領域に置かれ、利用者が自分で移動しない限り外部に出ることはありません。

### 連絡先へのアクセス
本アプリは、利用者が「電話帳に登録」を押したときにのみ連絡先を読み書きします。読み取りは、同じ人がすでに登録されていないかを電話番号とメールアドレスで照合するためだけに使います。連絡先データをアプリ外に送ることはありません。

### 権限
- カメラ: 名刺の撮影
- 連絡先の読み取り・書き込み: 上記の照合と登録
- 写真（アルバム）: 既存の写真からの取り込み

### 削除
アプリをアンインストールすると、端末内の保存データはすべて削除されます。連絡先に登録した情報は端末の連絡先アプリから削除してください。

### お問い合わせ
Google Play のストア掲載情報に記載の連絡先までご連絡ください。

## English

名刺スキャン (Meishi Scan, package jp.tobishoku.meishi_ocr, "the app") photographs business cards, recognises their text, and saves contacts to the device address book.

### Data collection
The app does not send any user data to any server. It has no network features and contains no analytics or advertising SDKs.

### Data handled on the device
- Card photos taken with the camera or chosen from the album
- Text recognised from those photos and the fields the user corrects (name, company, phone numbers, email, address, etc.)
- Memos the user types
- Correction rules learned from the user's edits

All of this is stored only in the app's private folder on the device (`Android/data/jp.tobishoku.meishi_ocr/files`). Backup zip files are written to the same folder and never leave the device unless the user moves them.

### Contacts access
The app reads and writes contacts only when the user taps "Register to contacts". Reading is used solely to check, by phone number and email, whether the same person already exists. Contact data is never transmitted anywhere.

### Permissions
- Camera: photographing cards
- Read/write contacts: the duplicate check and registration above
- Photos (album): importing existing photos

### Deletion
Uninstalling the app deletes all data stored by it on the device. Contacts already registered can be removed from the device's contacts app.

### Contact
Use the contact details on the app's Google Play listing.
