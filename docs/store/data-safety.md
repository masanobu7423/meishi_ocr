# Play Console「データ セーフティ」の回答（2026-11-03）

## 根拠

- 本アプリ自身が端末の外へ送るものはない。共有・カレンダー・ファイルの選択は利用者の操作による引き渡し、連絡先の同期は OS が行うもので、どちらも「収集」に当たらない。
- 製品版 v0.2.9 から内部テスト v0.2.15 までは、ML Kit（文字認識・ドキュメントスキャナー）が、診断と利用状況の分析のために次のものを HTTPS で Google に送る（https://developers.google.com/ml-kit/android-data-disclosure ）。端末の情報（メーカー・機種・OS）、アプリの情報（パッケージ名・バージョン）、インストールごとの識別子、性能の指標、API の設定、入出力の大きさ、イベントの種類、エラーコード。第三者への提供はない。
- v0.2.16 (19) 以降のリリース版は `INTERNET` 権限を持たないので、送らない。
- データ セーフティは「Google Play で配布中の版」の動作を書くもの。製品版が v0.2.9 のあいだは、ML Kit の送信を申告する。

## 今の回答（製品版が v0.2.15 以前のあいだ）

| 質問 | 回答 |
|---|---|
| 必須のユーザーデータの種類を収集または共有しますか | はい |
| 収集するデータは、送信時にすべて暗号化されますか | はい（ML Kit は HTTPS） |
| アカウントの作成方法 | アカウントを作成できない |
| データの削除をリクエストする方法がありますか | いいえ（アカウントがない。ML Kit のデータは開発者が保持しない） |

| データの種類 | 収集 | 共有 | エフェメラル処理 | 必須／任意 | 目的 |
|---|---|---|---|---|---|
| アプリのアクティビティとパフォーマンス → 診断情報 | はい | いいえ | いいえ | 必須 | 分析 |
| デバイスまたはその他の ID | はい | いいえ | いいえ | 必須 | 分析 |

上の 2 つ以外（位置情報、個人情報、連絡先、写真、ファイルなど）は「収集しない」。名刺・連絡先・写真は端末内で扱い、本アプリは送信しない。

## v0.2.16 以降が製品版に行き渡った後の回答

- 「必須のユーザーデータの種類を収集または共有しますか」→ いいえ（ML Kit の送信がなくなるため）
- あわせて、プライバシーポリシーの §1・§7・§8 を改める

## 実施記録

- 2026-11-03: 上の「今の回答」のとおりに Play Console のデータ セーフティを直して保存した（Claude が Chrome で操作、利用者の承認による）。それまでの申告は「収集・共有なし」だった。
  - プレビューで確かめた内容: 共有なし、収集は「診断情報」と「デバイスまたはその他の ID」（目的は分析）、送信中は暗号化、削除をリクエストする方法はなし、プライバシー ポリシーは https://masanobu7423.github.io/meishi_ocr/privacy.html
  - 公開の概要に「データ セーフティの質問票を完了」が 1 件、審査に未送信で残っている。**審査への送信は利用者が行う。**
  - 名刺スキャンのポリシーのステータスは「問題は検出されませんでした」。
