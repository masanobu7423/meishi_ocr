# 名刺スキャン v0.2.10 (13) — 内部テスト 11

- リリース名: `v0.2.10 (13) 内部テスト 11`
- versionName 0.2.10 / versionCode 13
- 機能の追加はありません。製品版 v0.2.9 (12) に対する基盤の更新です。

## リリースノート（日本語）

- Flutter を 3.47.8 に更新しました（Play Console の「エッジ ツー エッジで非推奨の API を使用」「一部のユーザーで有効にならない」の指摘に対する Flutter 側の修正を取り込みます）。
- 画面の端まで表示するエッジ・ツー・エッジを、Android 15 より前の端末でも有効にしました。
- リリースビルドで R8 の縮小・最適化を有効にしました。アプリのサイズとメモリ使用量が減ります。
- 動作は v0.2.9 と同じです。読み取り・連続撮影・電話帳への登録と同期・共有・バックアップが従来どおり動くことを内部テストで確認してください。

## Release notes (English)

- Flutter updated to 3.47.8 (brings the engine-side fixes for the Play Console edge-to-edge notices).
- Edge-to-edge display is now enabled on Android versions before 15 as well.
- Release builds use R8 shrinking and optimisation: smaller app, less memory.
- No functional changes from v0.2.9; please re-check scanning, burst capture, contact registration / sync, sharing and backup in internal testing.
