# 名刺スキャン v0.2.0 (2) — 内部テスト版

- リリース名: `v0.2.0 (2) 内部テスト 1`
- versionName 0.2.0 / versionCode 2（`pubspec.yaml` の `version: 0.2.0+2`）
- 配布: Google Play 内部テスト（AAB）。iOS は TestFlight 用の Codemagic 設定のみ（Mac 環境で実行）。
- 対象: Android 8.0 以上。日本語 OCR モデル同梱のため AAB は約 80 MB。

## リリースノート（日本語）

名刺を撮影して確認し、電話帳に登録するアプリの最初のテスト版です。通信は一切使いません。

**できること**
- 撮影時に名刺の辺を検出して正面から見た形に補正（ML Kit 文書スキャナ）。アルバムからの取込も同じ補正。
- 日本語名刺の氏名・ふりがな・会社・部署・役職・電話・携帯・FAX・メール・URL・郵便番号・住所を自動で振り分け。
- 読み取った文字をタップして項目に入れる確認画面。読み取れなかった必須項目を明示。
- 電話帳へ登録。姓名分割、ふりがな（印字がなければローマ字から変換）、電話のラベル付け。
- 同じ人がいるときは項目ごとに比較し、チェックで選んで統合・別人登録・既存の編集・削除ができる。統合は「元に戻す」可能。
- 保存した名刺の履歴（写真つき）と検索。メモ欄（会った場所・日付）。
- Obsidian 形式のノート出力、全件 vCard 書き出し、バックアップ zip。
- 手動で直した内容を次回から反映（同じ会社名や役職は自動で同じ項目へ）。
- ダークモード対応。

**既知の制限**
- 縦書きの名刺は読み取り精度が落ちます。確認画面で直してください。
- 同一人物の判定は電話番号とメールの一致のみです。
- バックアップは作成のみで、復元は zip を手動で展開します。
- iOS 版はこの配布に含まれません。

## Release notes (English)

First internal test build of 名刺スキャン, an offline business-card scanner for Japanese cards. No network access at all.

**What it does**
- Captures cards with on-device edge detection and perspective correction (ML Kit document scanner); album import gets the same correction.
- Splits Japanese cards into name, reading, company, department, title, phone, mobile, fax, email, URL, postal code and address.
- Review screen where recognised lines can be tapped into fields; missing core fields are called out.
- Registers to the device address book with family/given split, phonetic reading (derived from romaji when not printed) and labelled phones.
- When a matching contact exists, compares field by field with checkboxes: merge, register separately, edit the existing contact, or replace it. Merges can be undone.
- History of saved cards with photos and search; a memo field for where/when you met.
- Obsidian-style notes, vCard export of all cards, backup zip.
- Learns from manual corrections (the same company or title goes to the same field next time).
- Dark mode.

**Known limitations**
- Vertical-text cards read poorly; fix them on the review screen.
- Duplicate detection is exact match on phone or email only.
- Backup is create-only; restore by unzipping into the app folder.
- No iOS build in this distribution.

## テスター向けメモ / Tester notes

- 初回起動でカメラ、登録時に連絡先の権限を求めます。
- 読み取り結果は端末内 `Android/data/jp.tobishoku.meishi_ocr/files/` に保存され、Files アプリで見られます。
- 不具合は、読み取れなかった名刺の写真（個人情報に注意）と「どの項目がどう違ったか」を添えて報告してください。
