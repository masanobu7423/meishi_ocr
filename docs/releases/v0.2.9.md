# 名刺スキャン v0.2.9 (12) — 内部テスト 10

- リリース名: `v0.2.9 (12) 内部テスト 10`
- versionName 0.2.9 / versionCode 12
- コードの変更はありません。v0.2.8 (11) と同じ内容の内部テスト用ビルドです（署名はこのアプリのアップロード鍵 SHA1 0E:3A…）。v0.2.6 (9) 以降の内容をまとめます。

## リリースノート（日本語）

- Google の電話帳と同期できます。登録先に選んだ Google アカウントの連絡先を、端末の連絡先同期を通じて扱います（アプリは通信しません）。
- メニュー「電話帳から取り込む」で、電話帳の連絡先を名刺として取り込みます。登録済の名刺や同じ電話・メールの名刺は飛ばし、実行前に件数を確認できます。
- 電話帳に登録した名刺（取り込んだ名刺を含む）を修正して保存すると、電話帳の連絡先も更新されます。電話帳側だけにある電話・メール・メモは残します。
- 確認画面の「電話帳の内容を取り込む」で、電話帳側で直した内容を名刺に取り込めます（保存で確定）。
- 「職種」を登録項目に追加。選択肢は建設業種（鳶 / 足場 / 鉄筋 / 型枠 / 大工 / 左官 / 鉄骨 / 溶接 / 土木 / 舗装 / 解体 / 重機 / 電気 / 設備 / 配管 / 空調 / 塗装 / 防水 / 内装 / 板金 / 屋根 / 測量 / 施工管理 / 設計 / 不動産 / 営業 / 経営 / 事務 / その他）。読み取り時に部署・役職から推定して埋め、プルダウンで直せます。
- メニュー「職種の一覧を編集」で、職種を追加・名前変更・削除できます。一覧はバックアップにも含まれます。
- 「信頼度」を登録項目に追加。1〜5 をタップで選び、もう一度押すと解除。未設定でも保存できます。
- 職種と信頼度は Obsidian のノート属性（`job` / `trust`）とタグになり、`_名刺一覧.md` に「信頼度」列と「信頼度別」の節が加わります。
- 検索画面を職種・信頼度の絞り込みに特化。職種チップ（使っている値だけ）と信頼度の下限（全て / 3+ / 4+ / 5）、件数表示。一覧の行にも職種と信頼度を表示します。
- 共有: 確認画面の共有ボタン、長押し選択からの一括共有、「全件を vCard で共有」「バックアップを共有」。重複名刺の検出と、1 日 1 回の自動バックアップ。

## Release notes (English)

- Sync with Google Contacts through the device's contact sync for the account you register into; the app never goes online.
- Menu "電話帳から取り込む" imports the account's contacts as cards, skipping ones already registered or matching by phone / e-mail, with a count to confirm first.
- Saving an edited registered card updates the linked contact; numbers, e-mails and notes that exist only in Google are kept.
- "電話帳の内容を取り込む" on the review screen pulls the contact's current values into the card (save to confirm).
- New field 職種 (job): construction trades (scaffolding, rebar, formwork, carpentry, plastering…), pre-filled from department / title, editable from a dropdown; edit the list yourself from the menu (add / rename / delete), included in backups.
- New field 信頼度 (trust): a 1–5 rating chosen with one tap (tap again to clear; optional).
- Both become note properties and tags, with a 信頼度 column and section in the vault index for Obsidian Bases / Dataview.
- The search tab filters by job chips and a minimum trust level and shows the hit count; list rows show job and trust.
- Sharing (one card, a selection, all cards as vCard, a backup zip), duplicate detection and a daily automatic backup.
