# 名刺スキャン v0.2.13 (16) — 内部テスト 14

- リリース名: `v0.2.13 (16) 内部テスト 14`
- versionName 0.2.13 / versionCode 16
- コードの変更はありません。v0.2.12 (15) と同じ内容で、内部テスト用に版数だけ上げたビルドです。製品版 v0.2.9 (12) 以降の変更をまとめます。

## リリースノート（日本語）

- 「次回連絡日」を登録項目に追加。確認画面で日付を選ぶと、ホームに「連絡予定」（期限切れと 7 日以内の件数）が出て、一覧の「連絡予定」で近い順に確認できます。行には「連絡 11/03」「期限切れ 10/20」と表示します。
- 次回連絡日を端末のカレンダーに登録できます。日付の下の「カレンダーに登録」で、カレンダーアプリの新規予定画面が終日予定として開きます（タイトル「連絡: 氏名（会社）」、説明に電話・メール）。保存すれば Google カレンダーに同期され、通知はカレンダーの設定どおりに届きます。
- メニュー「連絡予定をカレンダーに書き出す（ics）」で、次回連絡日のある名刺をまとめて Google カレンダーや Outlook に取り込めます。
- メニュー「全件を CSV で共有（Excel 用）」を追加。確認画面と同じ項目を日本語の見出しで書き出し、Excel でそのまま開けます。
- 次回連絡日は Obsidian のノート（`next_contact`）と `_名刺一覧.md` の「連絡予定」、電話帳のメモ欄（「次回連絡:」）にも入ります。
- Flutter を 3.47.8 に更新し、画面の端まで表示するエッジ・ツー・エッジを古い Android でも有効にしました。リリースビルドで R8 の縮小・最適化を有効にし、サイズとメモリ使用量を減らしました。

## Release notes (English)

- New field 次回連絡日 (next contact date): pick a date on the review screen; Home shows a 連絡予定 tile (overdue + due within 7 days) and the list has a 連絡予定 filter, soonest first, with per-row 連絡 / 期限切れ badges.
- Add a follow-up to the phone's calendar: 「カレンダーに登録」 opens the calendar app's new-event screen as an all-day event (title 連絡: name (company), phone / e-mail in the description). Save it there and the calendar reminds you.
- Menu: export every follow-up as an iCalendar (.ics) file for bulk import into Google Calendar or Outlook.
- Menu: share all cards as an Excel-ready CSV (Japanese headers, UTF-8 with BOM).
- The date also goes to the Obsidian note (`next_contact`), a 連絡予定 section in the vault index, and the contact's note.
- Flutter updated to 3.47.8; edge-to-edge display on older Android versions too; release builds use R8 shrinking and optimisation.
