# 名刺スキャン v0.2.2 (5) — 内部テスト 3

- リリース名: `v0.2.2 (5) 内部テスト 3`
- versionName 0.2.2 / versionCode 5
- versionCode 4 は同一内容のビルドで、Play Console にはアップロードせずに 5 へ差し替えました。

## リリースノート（日本語）

- マイク（RECORD_AUDIO）権限を削除。camera プラグインが動画撮影用に付けていたもので、本アプリは音声を扱いません。
- アプリアイコンを新デザインに変更（内部テスト 1 以降の変更。v0.2.1 (3) は未配布）。
- ホーム / スキャン / 検索 / 一覧 のタブ構成、項目ごとに選べる統合画面、Google アカウントへの登録先選択、電話・メール・ウェブ・地図への移動、名刺写真のタップ拡大（同上）。

## Release notes (English)

- Removed the microphone (RECORD_AUDIO) permission; the camera plugin declared it for video, which this app never uses.
- New app icon (change since internal test 1; v0.2.1 (3) was never distributed).
- Home / Scan / Search / List tabs, per-field merge screen, choice of Google account, phone / mail / web / map hand-off, tap-to-zoom card photos (same).
