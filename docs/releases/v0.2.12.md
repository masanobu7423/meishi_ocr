# 名刺スキャン v0.2.12 (15) — 内部テスト 13

- リリース名: `v0.2.12 (15) 内部テスト 13`

## リリースノート（日本語）

- 次回連絡日を端末のカレンダーに登録できます。確認画面の日付の下の「カレンダーに登録」で、カレンダーアプリの新規予定画面が終日予定として開きます（タイトル「連絡: 氏名（会社）」、説明に電話・メール）。保存すれば Google カレンダーに同期され、通知はカレンダーの設定どおりに届きます。
- メニュー「連絡予定をカレンダーに書き出す（ics）」で、次回連絡日のある名刺をまとめて iCalendar ファイルにして共有できます。Google カレンダーや Outlook に一括で取り込めます。

## Release notes (English)

- Add a follow-up to the phone's calendar: 「カレンダーに登録」 under the date on the review screen opens the calendar app's new-event screen as an all-day event (title 連絡: name (company), phone / e-mail in the description). Save it there and the calendar reminds you.
- Menu: export every follow-up as an iCalendar (.ics) file and share it, for bulk import into Google Calendar or Outlook.
