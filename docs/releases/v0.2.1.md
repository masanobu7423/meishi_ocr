# 名刺スキャン v0.2.1 (3) — 内部テスト 2

- リリース名: `v0.2.1 (3) 内部テスト 2`
- versionName 0.2.1 / versionCode 3

## リリースノート（日本語）

内部テスト 1 からの変更点です。

- ホーム / スキャン / 検索 / 一覧 のタブ構成に変更。ホームに件数、最近の名刺、主要操作を表示。
- 同じ人がいるときの統合画面を項目ごとのチェックボックス式に。統合後のプレビュー、一括切替、取り消し。
- 登録先の Google アカウントを選べるように。未登録の名刺をまとめて電話帳に登録する機能を追加。
- 名刺の確認画面から電話・携帯・メール・ウェブ・地図へ移動できるチップを追加。名刺写真はタップで拡大。
- アプリアイコンを新デザインに変更。

## Release notes (English)

Changes since internal test 1.

- Home / Scan / Search / List tabs; home shows counts, recent cards and the main actions.
- Duplicate merge screen now uses per-field checkboxes with a preview, bulk toggles and undo.
- Choose the Google account to register into; bulk-register saved cards that are not in contacts yet.
- Phone, mobile, mail, web and map chips on the card screen; tap a card photo to zoom.
- New app icon.
