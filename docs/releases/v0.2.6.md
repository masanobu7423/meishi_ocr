# 名刺スキャン v0.2.6 (9) — 内部テスト 7

- リリース名: `v0.2.6 (9) 内部テスト 7`
- versionName 0.2.6 / versionCode 9
- v0.2.5 (8) の内容（共有、重複検出、自動バックアップ、白とティールの UI）を含みます。

## リリースノート（日本語）

- 「職種」を登録項目に追加。選択肢は建設業種（鳶 / 足場 / 鉄筋 / 型枠 / 大工 / 左官 / 鉄骨 / 溶接 / 土木 / 舗装 / 解体 / 重機 / 電気 / 設備 / 配管 / 空調 / 塗装 / 防水 / 内装 / 板金 / 屋根 / 測量 / 施工管理 / 設計 / 不動産 / 営業 / 経営 / 事務 / その他）。読み取り時に部署・役職の語から推定して埋め、確認画面のプルダウンで直せます（入力も可）。
- メニューの「職種の一覧を編集」で、職種を自由に追加・名前変更・削除できます。一覧はバックアップにも含まれます。
- 「信頼度」を登録項目に追加。1〜5 の段階をタップで選び、もう一度押すと解除。未設定のままでも保存できます。
- どちらも Obsidian のノートの属性（`job` / `trust`）とタグ（`#職種_…` `#信頼度_n`）に入り、`_名刺一覧.md` に「信頼度」列と「信頼度別」の節が加わります。Bases / Dataview でそのまま集計できます。
- 検索画面を職種・信頼度の絞り込みに特化。文字検索の下に職種チップ（使っている値だけ）と信頼度の下限（全て / 3+ / 4+ / 5）、右端に件数。一覧の行にも職種と信頼度を表示します。
- 電話帳に登録する連絡先のメモ欄にも「職種:」「信頼度:」の行が入ります。

## Release notes (English)

- New field 職種 (job): construction trades (scaffolding, rebar, formwork, carpentry, plastering…), pre-filled from department / title and editable from a dropdown.
- Edit the job list yourself from the menu (add / rename / delete); it is included in backups.
- New field 信頼度 (trust): a 1–5 rating chosen with one tap (tap again to clear; optional).
- Both become note properties (`job` / `trust`) and tags, with a 信頼度 column and section in the vault index, so Obsidian Bases / Dataview can group and sort on them.
- The search tab now filters by job chips and a minimum trust level, and shows the hit count; list rows show job and trust.
- Contact notes carry the job and trust lines too.
